## Phase 10 — Trust Calibration (Learning from Feedback)

**Goal:** The system improves over time by learning from human decisions on findings.

### 10.1 New file: `src/verdity/trust_calibration.py`

```python
class TrustCalibrator:
    """
    Learns from human feedback to improve confidence scoring.

    Non-negotiable: confidence scores remain deterministic (constraint #5).
    Trust calibration adjusts SEVERITY_WEIGHTS and CONCERN_BOOST
    based on historical outcome data, not per-finding LLM calls.
    """

    CREATE_TABLE_SQL = """
        CREATE TABLE IF NOT EXISTS trust_signals (
            id            INTEGER PRIMARY KEY AUTOINCREMENT,
            finding_type  TEXT NOT NULL,  -- agent + pattern_id
            outcome       TEXT NOT NULL,  -- 'confirmed', 'false_positive', 'wont_fix'
            repo_id       TEXT NOT NULL,
            timestamp     TEXT NOT NULL,
            confidence    REAL NOT NULL,
            severity      TEXT NOT NULL,
            concern       TEXT NOT NULL,
            UNIQUE(finding_type, repo_id, outcome, timestamp)
        );

        CREATE TABLE IF NOT EXISTS calibration_state (
            id            INTEGER PRIMARY KEY AUTOINCREMENT,
            version       INTEGER NOT NULL DEFAULT 1,
            weights_json  TEXT NOT NULL,  -- serialized adjusted weights
            last_trained  TEXT NOT NULL,
            sample_count  INTEGER NOT NULL DEFAULT 0,
            precision_at_09 REAL DEFAULT 0.0,
            recall_at_06    REAL DEFAULT 0.0
        );
    """

    async def record_outcome(
        self,
        finding_type: str,
        outcome: Literal["confirmed", "false_positive", "wont_fix"],
        repo_id: str,
        confidence: float,
        severity: str,
        concern: str,
    ) -> None:
        """Record a human decision on a finding."""
        ...

    async def recalibrate(
        self,
        min_samples: int = 50,
    ) -> CalibrationResult:
        """
        Recalibrate weights based on accumulated feedback.

        Returns CalibrationResult with:
        - adjusted_weights: dict of new severity/concern weights
        - precision_at_09: float (what % of auto-approved findings were confirmed)
        - recall_at_06: float (what % of confirmed findings scored >= 0.6)
        - sample_count: int
        - changed: bool (whether weights actually changed)
        """
        ...

    async def get_adjusted_weights(
        self,
    ) -> tuple[dict[str, float], dict[str, float]]:
        """
        Return current calibrated (severity_weights, concern_boost).

        Falls back to default weights if calibration hasn't run yet.
        """
        ...

    async def get_calibration_stats(
        self,
    ) -> dict[str, Any]:
        """Return current calibration state for dashboard display."""
        ...
```

## Phase 11 — Self-Review Adversarial Loop

**Goal:** After initial review, run a second pass to catch false positives. Target: 80-90% precision (SonarQube's published number).

### 11.1 New file: `src/verdity/adversarial_reviewer.py`

```python
class AdversarialReviewer:
    """
    Runs a second-pass review to challenge initial findings.

    Uses a different prompt/context than the initial agents
    to avoid self-confirmation bias (same principle as
    VerificationGate → VerifierSubagent separation).
    """

    async def challenge_findings(
        self,
        findings: list[Finding],
        diff: str,
        file_contents: dict[str, str],
        context: str = "challenging",
    ) -> list[AdversarialResult]:
        """
        For each finding, attempt to DISPROVE it.

        Returns list of AdversarialResult:
        - finding_id: str
        - verdict: Literal["confirmed", "disputed", "overturned"]
        - reasoning: str
        - suggested_confidence_adjustment: float  # -0.3 to +0.3
        - evidence: str  # code snippet supporting the verdict
        """
        ...

    async def _challenge_single(
        self,
        finding: Finding,
        diff: str,
        file_contents: dict[str, str],
    ) -> AdversarialResult:
        """Challenge a single finding by trying to disprove it."""
        ...

    def _apply_verdicts(
        self,
        findings: list[Finding],
        verdicts: list[AdversarialResult],
    ) -> list[Finding]:
        """
        Apply adversarial verdicts to findings.

        Rules:
        - 'confirmed' → keep finding, boost confidence slightly
        - 'disputed' → keep finding, reduce confidence, flag for manual review
        - 'overturned' → remove finding (false positive)
        """
        ...
```

### 12.2 Edit `src/verdity/agents/security.py`

```python
class SecurityAgent:
    async def review(
        self,
        diff: str,
        context: SemanticContext,
        file_contents: dict[str, str],
        use_llm: bool = False,  # new parameter
    ) -> AgentResult:
        # Pass 1: Deterministic regex (always runs)
        findings = self._regex_scan(diff, file_contents)

        # Pass 2: LLM-enhanced analysis (optional, metered)
        if use_llm and self.llm_client:
            llm_findings = await self._llm_scan(diff, context, file_contents)
            findings.extend(llm_findings)

        # Pass 3: Semantic context enrichment (always runs)
        enriched = self._enrich_with_context(findings, context)

        return AgentResult(findings=enriched, ...)
```

class Platform(ABC):
    """Base class for platform integrations."""

    @abstractmethod
    async def verify_webhook(
        self,
        headers: dict[str, str],
        body: bytes,
        secret: str,
    ) -> bool: ...

    @abstractmethod
    async def normalize_event(
        self,
        headers: dict[str, str],
        body: dict[str, Any],
    ) -> WebhookEvent: ...

    @abstractmethod
    async def post_comment(
        self,
        owner: str,
        repo: str,
        pr_number: int,
        body: str,
    ) -> dict: ...

        self,

        pr_number: int,
        commit_sha: str,
        file_path: str,
