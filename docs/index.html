Features

Built on non-negotiable constraints: deterministic confidence, audit-first design, and calibrated trust.

Constraint #5

Deterministic Confidence

Confidence scores computed by deterministic post-processing, never raw LLM self-report. Every finding's confidence is calibrated through the TrustCalibrator using human feedback.

Constraint #5: confidence computed by deterministic post-processing, never raw LLM self-report
Constraint #8

Token Economics

Every model/tool call metered through TokenEconomicsService. Per-review-run budgets, per-finding caps, degradation signals before hard limits.

TokenEconomicsService.record_call()
Constraint #9

Full Audit Trail

Append-only audit log with SHA-256 integrity checksums. Every finding, routing decision, approval action, and model call logged — no soft deletes, no updates.

AuditStore.append() → SHA-256 checksum
Constraint #9

Approval Queue

Sub-threshold findings never auto-post. Human approval required with SLA escalation, dual-secret rotation, and replay protection.

ApprovalQueue.enqueue() → SLA tracking
MCP Server

MCP Server

Model Context Protocol server exposing 8 tools: review_security, review_quality, review_testing, review_documentation, review_full, verdity_review, verdity_enforce, get_review_rules.

MCPServer.call_tool()
CLI

CLI Commands

Four commands: verdity-review, verdity-enforce, verdity-worker, verdity-enrich — with structured JSON output and atomic file writes.

verdity-review run --owner org --repo repo --pr 42

Quick Start

Install, configure, and run your first review in under 5 minutes.

1

Install

Install Verdity with pip. Requires Python 3.11+.

pip install verdity==0.5.0
Requires: Python 3.11+, GitHub App credentials
2

Configure

Copy .env.example to .env and add your GitHub App credentials.

cp .env.example .env
# Edit .env with your credentials:
WEBHOOK_HMAC_SECRET=...
GITHUB_APP_ID=123456
GITHUB_APP_INSTALLATION_ID=789012
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----..."
3

Run

Start the gateway and worker. Configure GitHub webhook to point to your gateway.

# Terminal 1: Start gateway
uvicorn verdity.gateway.app:app --reload --port 8000

# Terminal 2: Start worker
verdity-worker

# Terminal 3: Test review
verdity-review run --owner myorg --repo myrepo --pr 42

Configuration (.verdity.yml)

llm:
  enabled: true
  default_model: "qwen2.5-7b-instruct"
  default_backend: "ollama"
  ollama_url: "http://localhost:11434"
  
  enrichment:
    enabled: true
    default_mode: "explain"
    batch_size: 10
    timeout_seconds: 60
    async: true
  
  calibration_assist:
    enabled: true
    trigger_on_drift: true
    min_samples: 20
